You scan a document and half the pages come out sideways. Or you open a PDF and find certain pages are upside down. You rotate them in your PDF viewer - and then open the file again and they are sideways again.

This happens because PDF viewers can display pages rotated without actually saving the rotation to the file. Fixing this requires a tool that writes the rotation permanently into the PDF itself.

## Why Rotation Often Does Not "Stick"

PDF files contain a `Rotate` property for each page that specifies its display orientation. When you rotate a page in most PDF viewers (Preview on Mac, the browser's built-in viewer, some versions of Acrobat Reader), the viewer rotates the display without writing the change back to the file.

The result: the file opens sideways on every device because the underlying file was never changed.

To fix orientation permanently, you need a tool that actually modifies the `Rotate` value in the PDF page data and saves a new file.

## Common Causes of Incorrectly Oriented PDF Pages

**Scanning.** Scanners default to portrait orientation. Landscape documents or pages placed sideways in the feeder produce rotated pages.

**Phone camera scans.** Photos of documents taken in landscape mode may be saved with an orientation tag that not all PDF converters honor correctly.

**Mixed orientation documents.** A report with mostly portrait pages and a few landscape charts or tables can cause confusion when printed or shared.

**PDF export errors.** Some applications export PDFs with incorrect page rotation metadata.

## Rotating Individual Pages vs. the Entire Document

**Rotate all pages** when the entire scan came out sideways - for example, you placed the document in the feeder in the wrong direction.

**Rotate specific pages** when only some pages are affected - common in mixed-format documents where landscape charts are interspersed with portrait text pages.

**Rotate a range** when a continuous block of pages is incorrect - for example, a chapter that was scanned separately and inserted at the wrong orientation.

## Mixed Orientation Documents: A Practical Note

Some documents legitimately contain both portrait and landscape pages - a report where the main text is portrait but data tables are landscape. This is a valid PDF structure and does not need rotation correction.

Before rotating, verify whether pages are genuinely misoriented or intentionally landscape. A landscape page in a portrait document is correct if its content is a wide table or chart designed to be read sideways.
