You have a 60-page report and only need pages 12, 18, and 35. Or you received a PDF contract and need to save just the signature page. Extracting specific pages from a PDF is one of the most common document tasks - and one of the most misunderstood.

This guide explains exactly how to extract pages from a PDF for free, with no software to install.

## What "Extracting Pages" Actually Means

When you extract pages from a PDF, you are creating a new PDF that contains only the pages you selected. The original document is not modified - you end up with two files: the original and the extracted subset.

This is different from:

- **Splitting,** which divides a PDF into multiple separate files (e.g., every page becomes its own file)
- **Deleting pages,** which removes pages from the existing document rather than creating a new one
- **Copying text,** which pulls the text content out of pages without preserving formatting, images, or layout

Extracting preserves the full fidelity of the selected pages - fonts, images, vector graphics, and layout are identical to the original.

## When You Would Extract Pages

**Sharing a section of a larger document.** Instead of sending a 200-page report when the recipient only needs the executive summary, extract those pages into a separate file.

**Reusing content.** Pull specific pages from an existing PDF to combine with other documents using a merge tool.

**Reducing file size before sending.** A single-page invoice extracted from a 50-page statement is significantly smaller and easier to email.

**Creating a focused reference document.** Extract the relevant policy pages from a long handbook for easy access.

**Separating scanned pages.** If a multi-page scan came in as one PDF, extract individual pages to file them separately.

## Specifying Pages: Common Formats

Most PDF tools accept a range syntax for page selection:

| Input | What it extracts |
|---|---|
| `5` | Page 5 only |
| `1-10` | Pages 1 through 10 |
| `1, 5, 9` | Pages 1, 5, and 9 |
| `3-7, 15, 20-25` | Pages 3–7, then 15, then 20–25 |
| `last` | The last page only |

## Extracting vs. Splitting: Choosing the Right Approach

**Use Extract when** you know exactly which pages you want in one output file.

**Use Split when** you want to divide the whole document - for example, splitting every 10 pages into separate files, or splitting at specific page boundaries.

Both operations leave the original PDF untouched.
